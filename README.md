# Katinfilms — Portafolio audiovisual

Portada dividida Cine / Corporativo. Vite + JavaScript vanilla + GSAP (Flip) + Lenis.

## Uso

```bash
npm install
npm run dev       # servidor de desarrollo en http://localhost:5173
npm run build     # build de producción en dist/
npm run preview   # sirve dist/ localmente
```

Requiere Node ≥ 20. Copiar `.env.example` a `.env` si se necesitan variables.

Especificación completa, estructura y reglas: [docs/SPECS.md](docs/SPECS.md).
